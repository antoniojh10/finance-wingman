# Security policy

## Reporting a vulnerability

Report vulnerabilities privately with GitHub private vulnerability
reporting: open the repository's **Security** tab and choose **Report a
vulnerability**.

Do not open a public issue, pull request or discussion for a security
problem.

Include what is affected, steps to reproduce, and the impact you expect. Reports
are handled on a best-effort basis.

## Scope

This policy covers the code in this repository: the Go API (REST, MCP and
OAuth) and the Next.js web app. Problems in third-party dependencies should
be reported to their maintainers.
